# Security

The updater downloads and installs files, so security reports are welcome.

**Report a problem privately:** open the repository's **Security** tab and choose **Report a vulnerability**.
Please do not describe a security problem in a public issue.

What helps: the updater version (shown in its window), Windows or Linux, and the steps that show the problem.

Every release lists the SHA-256 checksums of its files in `SHA256SUMS.txt`, and the updater installs only
files that match a checksum published with their release.
